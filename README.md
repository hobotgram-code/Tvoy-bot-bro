# 🤖 Твой Бот-Бро — трекер зависимостей для Telegram

Личный бот-мотиватор, который помогает бросить вредные привычки: **курение**, **алкоголь**,
**порно/онанизм (NoFap)**, **плохое питание** — и любую свою цель.

Считает стрик до минуты, выдаёт уровни за силу воли, показывает как восстанавливается
организм, считает сэкономленные деньги и присылает утреннюю мотивацию и вечерний чек-ин.

## ✨ Возможности

- ⏱ **Точный стрик** — время без зависимости с точностью до минут
- 🏅 **Уровни** — 12 уровней от «🌱 Новичок» до «🚀 Легенда»
- 🩺 **Вехи здоровья** — реальные этапы восстановления организма (пульс, лёгкие, печень, сон…)
- 💰 **Экономия денег + мечта** — сколько сберёг и прогресс к цели-покупке
- 🆘 **Кнопка «Паника»** — экстренная помощь в момент тяги: дыхание 4-4-4, отвлекающий
  челлендж, твоё «зачем» и напоминание, что потеряешь при срыве
- 📈 **Календарь-график** — GitHub-подобный heatmap чистых дней (PNG)
- 🎯 **Мечта-цель** — привяжи покупку к экономии и следи за прогрессом
- 🏆 **Достижения (12 ачивок)** — открываются автоматически, дают XP
- 🎖 **Профиль, XP и ранги** + анонимный рейтинг по стрику
- 🧩 **Ежедневные квесты** — маленькое полезное действие каждый день и серия
- 📔 **Дневник срывов** — фиксирует триггер и настроение, показывает твои паттерны
- 📈 **Умные напоминания** — превентивный сигнал в статистически опасный день недели
- 🤝 **Режим напарника** — друг получает сигнал о срывах и видит твой стрик
- 💊 **Радар замен** — здоровые альтернативы под каждую привычку
- 💥 **Кнопка «Срыв»** — честный сброс без осуждения, рекорд сохраняется
- 💪 **Тренировки** — отжимания/турник/брусья 5 дней в неделю с ростом повторений и кнопками «Выполнил/Пропустил»
- 📸 **Прогресс-фото** — храню снимки и раз в неделю показываю прошлый для сравнения
- 🌿 **Витамины** — подборки и напоминания для восстановления (алкоголь, питание, курение, NoFap)
- 🧘 **Библиотека техник** — дыхание 4-7-8, заземление 5-4-3-2-1, сёрфинг по тяге и др.
- 📅 **Недельный отчёт** — авто-сводка по понедельникам: стрик, экономия, срывы, тренировки, XP
- 💬 **Личные аффирмации** — свои фразы, которые бот напоминает по утрам
- 📈 **Замеры** — вес и самочувствие с графиком динамики
- 🎁 **Награды за майлстоны** — бот подсказывает, что купить на сэкономленное
- ❄️ **Заморозка стрика** — спасает стрик 1 раз в месяц при случайности
- 📤 **Экспорт данных** — выгрузка всей статистики в JSON
- 🤖 **ИИ-собеседник** — поддержка в чате на базе Claude (опционально, нужен API-ключ)
- ⏰ **Гибкое время уведомлений** — свой час для утра/вечера/тренировки
- 🔔 **Умные уведомления** — превентив в опасный день недели, вечерний чек-ин
- 💡 **Советы** — техники и мотивация, когда тяжело
- 🎯 **Свои цели** — можно трекать что угодно

## 🚀 Быстрый старт (локально)

```bash
# 1. Получи токен у @BotFather в Telegram (команда /newbot)
# 2. Установи зависимости
pip install -r requirements.txt

# 3. Задай токен и запусти
export BOT_TOKEN="ТВОЙ_ТОКЕН"
python bot.py
```

Открой бота в Telegram, нажми **/start** — и добавляй первый трекер.

## ☁️ Деплой на бот-хост

Проект готов к заливке на любой хостинг для ботов (bothost.ru, Amvera, Railway, Render,
Heroku-совместимые и т.п.).

### Общая инструкция

1. **Создай бота** у [@BotFather](https://t.me/BotFather) → команда `/newbot` → скопируй токен.
2. **Залей репозиторий** на хост (через Git или загрузкой файлов).
3. **Добавь переменную окружения** `BOT_TOKEN` со своим токеном
   (в настройках проекта на хосте — секцию Environment / «Переменные»).
4. **Команда запуска:** `python bot.py`
   (на большинстве хостов это указано в `Procfile`: `worker: python bot.py`).
5. Хост сам установит зависимости из `requirements.txt`.

### Конкретно bothost.ru

1. Создай проект → загрузи файлы репозитория (или подключи GitHub).
2. В настройках проекта пропиши переменную окружения `BOT_TOKEN`.
3. Точка входа / команда запуска: `bot.py` (или `python bot.py`).
4. Запусти проект — бот начнёт работать в режиме polling, вебхуки не нужны.

> ⚠️ База данных — файл `tracker.db` рядом с ботом. Если хост «эфемерный»
> (пересоздаёт файловую систему при рестарте), подключи постоянный диск и укажи
> путь через переменную `DB_PATH`, иначе прогресс сбросится при перезапуске.

## ⚙️ Переменные окружения

| Переменная     | Обязательна | По умолчанию | Описание                                    |
|----------------|-------------|--------------|---------------------------------------------|
| `BOT_TOKEN`    | ✅ да       | —            | Токен от @BotFather                          |
| `DB_PATH`      | нет         | `tracker.db` | Путь к файлу базы SQLite                      |
| `TZ_OFFSET`    | нет         | `3`          | Часовой пояс по умолчанию (3 = МСК)          |
| `MORNING_HOUR` | нет         | `9`          | Час утреннего уведомления (локальное время)  |
| `EVENING_HOUR` | нет         | `21`         | Час вечернего чек-ина                         |
| `VITAMIN_HOUR` | нет         | `10`         | Час напоминания о витаминах                   |
| `WORKOUT_HOUR` | нет         | `17`         | Час напоминания о тренировке                  |
| `WORKOUT_DAYS` | нет         | `0,1,2,3,4`  | Дни тренировок (0=Пн … 6=Вс)                  |
| `PHOTO_HOUR`   | нет         | `12`         | Час еженедельного напоминания о фото          |
| `PHOTO_WEEKDAY`| нет         | `6`          | День недели для фото (6 = воскресенье)         |
| `ANTHROPIC_API_KEY` | нет    | —            | Ключ Claude API — включает ИИ-собеседника     |
| `AI_MODEL`     | нет         | `claude-opus-4-8` | Модель для ИИ-собеседника                |

> ⏰ Утро/вечер/тренировку каждый пользователь может переопределить прямо в боте
> (⚙️ Настройки → ⏰ Время уведомлений). Значения выше — только дефолты.

## 🗂 Структура проекта

```
bot.py         — точка входа, запуск polling и планировщика
config.py      — чтение настроек из окружения
content.py     — привычки, вехи, уровни, советы, квесты, замены, триггеры
database.py    — работа с SQLite (aiosqlite) + миграции
handlers.py    — обработчики команд и кнопок
keyboards.py   — клавиатуры
cards.py       — карточки прогресса, профиль, дневник, отчёт, замеры, тренировки
achievements.py — система достижений и XP
charts.py      — календарь чистых дней и график веса (matplotlib)
ai.py          — ИИ-собеседник на Claude API (опционально)
scheduler.py   — уведомления, тренировки, витамины, фото, отчёты (APScheduler)
utils.py       — время, склонения, уровни, прогресс-бары
```
